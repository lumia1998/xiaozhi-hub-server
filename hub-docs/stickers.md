# 表情包

管理后台的「模型与能力 → 表情包」可以上传、打标、启用、停用和删除图片。支持 PNG、JPEG、WebP、GIF，动图保留原始动画。每张最大 5 MB，最多保存 200 张。

每张表情包含名称、情绪与语义标签、图片内容和适用语境。标签用于检索，图片内容与适用语境供模型判断是否适合当前聊天。管理员也可写明应避免的语境。

「使用视觉模型打标」调用 `selected_module.VLLM` 指定的视觉服务，生成可编辑的标签草稿，保存后生效。调用时图片会发送至该视觉服务。图片在服务器缩小至最长边 768 像素，动图取首帧。配置或调用失败时，仍可手动填写所有字段。

Pi 聊天会在设备声明支持图片媒体时提供 `search_stickers` 与 `send_sticker` 工具。检索返回最多 8 个已启用候选，模型根据标签、画面和语境选择，每轮最多发送一张。回复继续经过现有 TTS 管线，图片通过媒体消息展示并保存到聊天历史。

图片与元数据存储于用户配置目录下的 `stickers.db`。保存与删除使用 SQLite 事务，编辑使用版本检查防止覆盖其他管理员的修改。备份时可在服务停止后复制数据库。

图片地址形如 `/media/stickers/<随机编号>`，持有完整地址即可读取，便于音箱直接加载。停用后停止提供给模型，历史图片仍可加载。删除后相应历史图片会失效。

图片的设备访问地址优先采用 `server.media_base_url` 或有效的 `server.vision_explain` 地址的协议与主机。未配置时使用当前 WebSocket 的本机地址及 `server.http_port`，通配或回环地址回退至服务器局域网 IP。通过反向代理访问时可显式设置 `server.media_base_url` 为外部 HTTP(S) 源站地址。

## 验证

在仓库根目录运行以下命令。

```sh
PYTHONDONTWRITEBYTECODE=1 test/.venv/bin/python -m pytest -c test/pytest.ini test/test_stickers.py test/test_media_output.py -q
```

测试使用临时图片和数据库，视觉模型与 LLM 响应采用替身。上线后需要使用已配置的视觉服务验证标签质量，并在支持媒体的音箱上检查显示。
